# 📊 World Wide Importers Sales Dashboard

## Project Overview

This project is an interactive Microsoft Excel dashboard developed using the World Wide Importers dataset. It provides business insights into sales performance, revenue, profit, employee performance, sales territories, product sales, and city-wise analysis through interactive visualizations.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filter
- Conditional Formatting
## Dashboard Features
- 📈 Revenue & Profit by Employee
- 👨‍💼 Sales Performance by Employee
- 🌍 Profit by Sales Territory
- 📦 Total Selling Products
- 📊 Monthly Sales Trend
- 🏙️ Top 10 Cities by Sales
- 🎛️ Interactive filters for Fiscal Year, Sales Territory, and Timeline
