# 🏏 IPL Match Analysis Dashboard

## Project Overview

This project is an interactive Match Analysis Dashboard built in Microsoft Excel using IPL match data. It provides insights into team performance, player statistics, venues, toss wins, and yearly match trends through interactive visualizations.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filter
- Conditional Formatting

## Dashboard Features

- 🏟️ Matches by Venue
- 📅 Year-wise Total Matches
- 🏆 Man of the Match Awards
- 🥇 Top 10 Batsmen
- 🪙 Toss Wins by Team
- 🏏 Matches Won by Team
- 🎛️ Interactive Team and Timeline Filters
